# 🛒 FakeStore API Testing Project

## 📌 Overview

This project demonstrates API testing using Postman on FakeStore API.

## 🚀 Features Covered

* CRUD Operations (GET, POST, PUT, DELETE)
* API Chaining (Create → Update → Delete)
* Environment Variables
* Test Scripts (Assertions)
* Collection Runner (Automation)

## 🛠 Tools Used

* Postman
* FakeStore API

## ▶️ How to Run

1. Import Collection JSON into Postman
2. Import Environment JSON
3. Select Environment
4. Run Collection using Runner

## 📂 Files

* FakeStore_API_Collection.json
* FakeStore_Environment.json
